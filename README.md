## Experiment 1: Tensor Operations using PyTorch and NumPy

* Created 1D, 2D, and 3D tensors using PyTorch and NumPy.
* Performed basic element-wise operations: addition, subtraction, multiplication, and division.
* Implemented dot product and matrix multiplication.
* Demonstrated indexing and slicing, including boolean masking and extracting subtensors.
* Applied tensor shape manipulation using .view(), .reshape(), .unsqueeze(), and .squeeze() in PyTorch and compared with NumPy .reshape().
* Explored broadcasting with tensors of different shapes.
* Compared in-place and out-of-place operations in PyTorch to understand memory and computation behavior.
